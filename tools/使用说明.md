# MiMo Switch 使用说明

把小米 MiMo 桌面端的免费额度，变成本机的 OpenAI / Anthropic / Responses 兼容端点，
供 Claude Code、Codex、Cursor、Cline 等工具使用。

## 你需要什么

- Windows 10 / 11 和一个小米账号。
- **首次取凭证时**，这台电脑上要装有 MiMo 桌面端并登录一次。取到凭证之后，
  MiMo 可以完全关闭，日常使用不再需要它（会话由本工具自己静默续期）。

## 安装

1. 解压 `mimo-switch-win-x64.zip` 到任意文件夹。
2. 在该文件夹里右键 `install.ps1` → 「使用 PowerShell 运行」
   （或命令行执行 `powershell -ExecutionPolicy Bypass -File install.ps1`）。
3. 它会复制到 `%LOCALAPPDATA%\MiMoSwitch`、创建开始菜单项、注册开机静默自启并启动。
   不想安装也可以：直接把 `MiMoSwitch.exe` 放任意位置双击，效果相同（只是不会自启）。

## 第一次取凭证

在 `%LOCALAPPDATA%\MiMoSwitch` 里执行：

```
MiMoSwitch.exe harvest --launch
```

它会以调试端口启动 MiMo，你在 MiMo 自己的窗口里正常登录（扫码或密码）。
登录完成后本工具读取那次登录得到的会话并加密保存（Windows DPAPI，只对
本机的当前用户可解）。此后 MiMo 可以退出，反代照常工作。

> 托盘和主界面上还有一个「登录／重新授权小米账号」，它不经过 MiMo，而是在本工具
> 自己打开的一次性浏览器窗口里登录。小米目前会在这种窗口的换票第二步拒绝，
> 所以它仍是实验入口；日常请用上一步的 `harvest`。

## 日常使用

- 托盘图标右键：打开主界面 / 立即续期会话 / 开机静默自启 / 退出应用。
- 主界面 <http://127.0.0.1:7864/>：剩余用量、会话状态、以及 Claude Code、Codex、
  Cursor 的现成配置（旁边有复制按钮）。
- 端点只监听 `127.0.0.1`，并要求本地令牌；同机其他程序可读到该令牌，外网不行。
- 会话失效会自动续期；如果自动续期失败，重跑一次 `harvest --launch`。

## 额度

按 **token × 模型倍率** 折算：Flash 0.4 倍、Pro 1 倍、Ultraspeed 10 倍（主界面的模型表
会标出最省的）。日常任务建议固定用 Flash，否则额度会快好几倍地耗尽。

## 卸载

1. 托盘右键 → 退出应用。
2. 运行 `MiMoSwitch.exe autostart off`。
3. 删除 `%LOCALAPPDATA%\MiMoSwitch` 与 `%APPDATA%\mimo-switch`（后者是配置和加密凭证）。

## 注意

- 这是非官方的逆向接入工具：小米随时可能改动接口或收紧策略，届时需要更新本程序。
- 接入其他工具消耗的是你账号的免费额度，请自行确认是否符合小米的服务条款；
  不要把端点或本地令牌交给他人。
- 日志在 `%APPDATA%\mimo-switch\tray.log`，出问题时先看它。
