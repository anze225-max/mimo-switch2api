# MiMo Switch 使用说明

把小米 MiMo 桌面端的免费额度，变成本机的 OpenAI / Anthropic / Responses 兼容端点，
供 Claude Code、Codex、Cursor、Cline 等工具使用。**只有一个 exe，双击即完成安装。**

## 你需要什么

- Windows 10 / 11 和一个小米账号。
- 该账号要有 MiMo 桌面端的免费额度（通常意味着装过并用过一次 MiMo 桌面端）。
- 取凭证不需要 MiMo 运行：登录发生在本工具自己打开的小米官方登录窗口里。

## 安装 = 双击

解压后双击 `MiMoSwitch.exe`，它会自动完成：

1. 把自己安置到 `%LOCALAPPDATA%\MiMoSwitch\`，并改从那里运行
   （所以你把下载目录清掉也不影响开机自启）；
2. 注册开机静默自启（无窗口，日志进文件）；
3. 在开始菜单放两项：**MiMo Switch** 和 **卸载 MiMo Switch**；
4. 首次没有凭证时弹出小米官方登录窗口，扫码或输密码登录即可。

登录窗口用的是本工具自己的临时资料目录：不进你的日常浏览器，不读取任何其他程序的数据，
登录完成后该目录即被删除。之后 MiMo 装不装、开不开都无关，会话到期自动续期。

也可以不安置：命令行运行 `MiMoSwitch.exe serve` 就地临时跑一次。

## 卸载 = 一键

开始菜单点「卸载 MiMo Switch」（或运行 `MiMoSwitch.exe uninstall`），确认框里会列出将要删除的内容：
开机自启项、开始菜单快捷方式、程序目录、配置与凭证。点「是」即全部清掉，程序自己删除自身目录。
想保留账号凭证（下次装回来不用重新登录）就加 `--keep-config`。

## 接入工具

打开主界面 <http://127.0.0.1:7864/>，上面有现成配置和复制按钮：

- **Claude Code**：`ANTHROPIC_BASE_URL=http://127.0.0.1:7864/v1`、`ANTHROPIC_API_KEY=<面板里的本地令牌>`
- **Codex**：`~/.codex/config.toml` 里加 `[model_providers.mimo]`，`wire_api = "responses"`
- **Cursor / Cline / 其他 OpenAI 兼容工具**：base_url 同上

模型建议填 `mimo-v2.6-flash`（0.4 倍最省），主界面的模型表会标出最省的那个。

## 可设置的参数

主界面「启动与保活」区（改动即时生效并写入配置）：

- **开机静默自启**：开/关。
- **端点中断后自动重启**：端口被别的程序抢走或监听异常退出时，按 1s→3s→9s→27s→30s 退避重试，
  不再整个程序退出；主界面会显示「已自动重启 N 次」。
- **保活续期间隔（分钟）**：默认 360（6 小时）主动换一次 serviceToken，不等请求撞 401 才补；
  填 0 关闭。

托盘右键同样有：打开主界面 / 登录／重新授权 / 立即续期会话 / 开机静默自启 / 退出应用。

## 额度

按 **token × 模型倍率** 折算：Flash 0.4 倍、Pro 1 倍、Ultraspeed 10 倍。日常任务建议固定用
Flash，否则额度会快好几倍地耗尽。

## 注意

- 端点只监听 `127.0.0.1` 且要求本地令牌；同机其他程序能读到该令牌，外网不能。别把令牌外传。
- 这是非官方的逆向接入工具：小米随时可能改动接口或收紧策略，届时需要更新本程序。
- 用它接入其他工具消耗的是你账号的免费额度，请自行确认是否符合小米的服务条款。
- 日志在 `%APPDATA%\mimo-switch\tray.log`（超过 2MB 启动时滚动），出问题时先看它。
- 重复双击不会开出第二个实例：它会打开已运行实例的主界面。
