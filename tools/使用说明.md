# MiMo Switch 使用说明

把小米 MiMo 桌面端的免费额度，变成本机的 OpenAI / Anthropic / Responses 兼容端点，
供 Claude Code、Codex、Cursor、Cline 等工具使用。

## 你需要什么

- Windows 10 / 11 和一个小米账号。
- 该账号要有 MiMo 桌面端的免费额度（通常意味着你装过并用过一次 MiMo 桌面端）。
- **取凭证不需要 MiMo 运行**：登录发生在本工具自己打开的小米官方登录窗口里。

## 安装

1. 解压 `mimo-switch-win-x64.zip` 到任意文件夹。
2. 右键 `install.ps1` → 「使用 PowerShell 运行」
   （或命令行 `powershell -ExecutionPolicy Bypass -File install.ps1`）。
3. 它会复制到 `%LOCALAPPDATA%\MiMoSwitch`、创建开始菜单项、注册开机静默自启并启动。
   不想安装也行：把 `MiMoSwitch.exe` 放任意位置双击，效果相同（只是不会自启）。

## 第一次登录

双击 `MiMoSwitch.exe`（或在托盘右键选「登录／重新授权小米账号」、或打开主界面点登录按钮），
会弹出一个**小米官方登录页**窗口：扫码或输密码都行。

- 这个窗口用的是本工具自己的临时资料目录，不进你的日常浏览器，也不读取任何其他程序的数据；
  登录完成后临时目录会被删除。
- 工具从中只保留你自己账号的长期凭证（用 Windows DPAPI 加密，只对本机当前用户可解）。
- 之后 MiMo 装不装、开不开都无关；会话到期会自动续期。

万一这条路被你的网络环境挡住（例如代理拦截了新窗口），有兜底办法：装好 MiMo 并登录后执行
`MiMoSwitch.exe harvest --launch`，它会带调试端口启动 MiMo 并接管那次登录得到的会话。

## 日常使用

- 托盘图标右键：打开主界面 / 登录／重新授权 / 立即续期会话 / 开机静默自启 / 退出应用。
- 主界面 <http://127.0.0.1:7864/>：剩余用量、会话状态（含凭证指纹，便于确认是否轮换过）、
  以及 Claude Code、Codex、Cursor 的现成配置（每块旁边有复制按钮）。
- 端点只监听 `127.0.0.1`，并要求本地令牌；同机其他程序可读到该令牌，外网不行。
- 支持图片输入：截图、读图在 OpenAI、Anthropic、Responses 三条端点上都可用。

## 额度

按 **token × 模型倍率** 折算：Flash 0.4 倍、Pro 1 倍、Ultraspeed 10 倍（主界面的模型表会标出
最省的）。日常任务建议固定用 Flash，否则额度会快好几倍地耗尽。

## 卸载

1. 托盘右键 → 退出应用。
2. 运行 `MiMoSwitch.exe autostart off`。
3. 删除 `%LOCALAPPDATA%\MiMoSwitch` 与 `%APPDATA%\mimo-switch`（后者是配置和加密凭证）。

## 注意

- 这是非官方的逆向接入工具：小米随时可能改动接口或收紧策略，届时需要更新本程序。
- 接入其他工具消耗的是你账号的免费额度，请自行确认是否符合小米的服务条款；
  不要把端点或本地令牌交给他人。
- 日志在 `%APPDATA%\mimo-switch\tray.log`（超过 2MB 会在启动时滚动），出问题时先看它。
