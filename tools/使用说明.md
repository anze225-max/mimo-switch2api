# MiMo Switch 使用说明

把小米 MiMo 桌面端的免费额度，变成本机的 OpenAI / Anthropic / Responses 兼容端点，
给 Claude Code、Codex、Cursor、Cline 等工具使用。

## 你需要什么

- Windows 10 / 11，以及一个小米账号。
- 不需要在这台电脑上安装 MiMo 客户端，也不需要让它保持运行。

## 安装

1. 解压 `mimo-switch-win-x64.zip` 到任意文件夹。
2. 在该文件夹里右键 `install.ps1` → 「使用 PowerShell 运行」
   （或命令行执行 `powershell -ExecutionPolicy Bypass -File install.ps1`）。
3. 程序会复制到 `%LOCALAPPDATA%\MiMoSwitch`，创建开始菜单项，注册开机静默自启，然后启动。
4. 首次启动会弹出一个小米官方登录窗口。用扫码或账号密码登录即可，登录完成前不要关掉它。

不想安装也可以：直接把 `MiMoSwitch.exe` 放到任意位置双击，效果相同（只是不会自启）。

## 登录后

- 系统托盘会有 MiMo 图标：右键可「打开主界面」「登录／重新授权」「立即续期会话」「开机静默自启」「退出应用」。
- 主界面 <http://127.0.0.1:7864/> 显示剩余用量、当前会话和各家工具的接入配置，配置块右边有复制按钮。
- 端点只监听 `127.0.0.1`，且要求带本机令牌；同一台机器上的其他程序能读到它，外网不能。

## 会话与额度

- 登录成功后程序保存的是你自己账号的长期凭证（用 Windows 的 DPAPI 加密，只在这台电脑、这个登录用户下可解），
  之后每次启动会静默换取短期会话，不需要再登录，也不需要开 MiMo。
- 会话失效时会自动续期；续期不成功就在托盘点「登录／重新授权」，或在主界面按登录按钮。
- 额度是按 **token × 模型倍率** 折算的，Flash 0.4 倍、Pro 1 倍、Ultraspeed 10 倍，
  日常任务建议用 Flash。主界面的模型表会标出最省的那个。

## 卸载

1. 托盘右键 → 退出应用。
2. 运行 `MiMoSwitch.exe autostart off`（或在托盘里取消勾选「开机静默自启」）。
3. 删除 `%LOCALAPPDATA%\MiMoSwitch` 和 `%APPDATA%\mimo-switch`（后者保存配置与加密凭证）。

## 注意

- 这是非官方的逆向接入工具：小米随时可能改动接口或收紧策略，届时需要更新本程序。
- 用它接入其他工具会消耗你账号的免费额度，请自行确认是否符合小米的服务条款；
  不要把端点或本机令牌透露给他人。
- 日志在 `%APPDATA%\mimo-switch\tray.log`，出问题时先看它。
