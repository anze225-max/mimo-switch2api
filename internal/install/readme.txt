MiMo Switch 使用说明
====================

把 MiMo 桌面端的免费额度暴露成本地 OpenAI 协议端点。目前仅支持 Windows 系统。

面板：双击 MiMoSwitch.exe 后浏览器打开 http://127.0.0.1:7864/ ，接入配置里有三项：

  接口地址  http://127.0.0.1:7864/v1
  API Key   面板里的本地令牌
  模型      面板里给出（建议最省额度的那个）

本端点使用 OpenAI 协议：把这三项填进任何支持 OpenAI 接口的工具
（OPENAI_BASE_URL / OPENAI_API_KEY / model）即可，无需其他配置。支持图片输入。

常用
----
· 登录／重新授权：面板上的按钮，窗口里显示的是小米官方登录页。
· 开机自启、崩溃自动重启、保活续期：面板「启动与保活」里配置。
· 卸载：双击本目录的「卸载 MiMo Switch.exe」，会连本目录一起删干净；
  命令行加 --keep-config 可保留账号凭证。若目录里有不是本程序的文件，
  卸载会保留整个目录并提示你自行确认。

本项目为非官方第三方工具，仅供学习与研究用途，使用须遵守小米的服务条款与法律：
https://github.com/anze225-max/mimo-switch2api
